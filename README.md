## 🤖 AI Projects

#### 🔎 Multi-Tenant RAG Service
Production RAG API built with **Python, FastAPI, ChromaDB, and Ollama**. Features token streaming via Server-Sent Events (SSE), tenant-isolated retrieval enforced per request (verified zero cross-tenant leakage), cost/latency observability middleware, and provider-failure handling. Demonstrates RAG delivered as a secure, scalable service.

#### 🔌 MCP Server & Client
Both halves of a **Model Context Protocol** integration — a server exposing tools and resources, and a client that discovers and calls them at runtime, wired into a local-model agent loop. Shows the modern standard for connecting AI to internal systems.

#### 🧠 Agentic System (ReAct)
An LLM agent with a **think → act → observe** tool-calling loop, step-limit safety caps, and schema validation at the tool boundary. Implemented in raw orchestration **and** rebuilt in **LangGraph** to demonstrate both fundamentals and framework fluency.

#### 🎫 Support Ticket Triage Engine
LLM system that classifies priority, extracts structured fields, and drafts replies from raw tickets — featuring graceful degradation and clean engine/interface separation for production use.

#### 🛒 Retail Shelf Detection & Recognition
Computer-vision pipeline integrating **YOLO** for shelf/product detection, **OCR** for on-shelf text extraction, and **ArcFace** for face recognition — combining multiple deep-learning models into one working system.

#### 🧾 ZATCA Phase 2 E-Invoicing
Saudi Arabia e-invoicing compliance implementation (Fatoora, XML generation, certificate signing) — direct experience with Kingdom of Saudi Arabia (KSA) regulatory requirements.
